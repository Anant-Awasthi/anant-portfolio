# Anant Awasthi | AI Developer & GTM Portfolio 🚀

An interactive, high-performance developer portfolio showcasing product orchestration, automated GTM workflows, and full-stack AI integrations.

## 🛠 Tech Stack
- **Framework:** TanStack Start / React / Vite
- **Styling:** Tailwind CSS v4 (Glassmorphism UI)
- **AI Integration:** Google Gemini 1.5 API (`Ask Anant AI` serverless endpoint)
- **Deployment:** Vercel Infrastructure

## 🌟 Key Features
- **Ask Anant AI:** Live AI assistant trained to answer queries about projects and skills with fallback mock responses.
- **Glassmorphism UI:** Smooth animations, custom theme toggles, and responsive layouts.
- **Serverless API Routes:** Direct REST integrations to prevent key leaks and ensure fast response times.
